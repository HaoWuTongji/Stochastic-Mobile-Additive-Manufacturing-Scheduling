# MAM-VPRP 动态调度实验程序与归档材料

## 1. 项目说明

本项目为毕业设计相关程序与实验材料，主要围绕 MAM-VPRP 问题开展确定性优化、仿真评估、仿真优化算法、深度强化学习动态调度算法及消融实验研究。

项目内容主要包括：

1. MAM-VPRP 问题的确定性等价 MILP 数学模型；
2. 面向 MAM-VPRP 问题的仿真评估环境；
3. 基于确定性等价模型的求解与仿真评估程序；
4. SIM-ALNS 仿真优化算法及 EXP-ALNS 基准算法；
5. 基于 PPO 的动态调度强化学习环境与训练程序；
6. 动作空间消融实验环境与训练程序；
7. 训练完成的 PPO 策略模型文件；
8. 算例数据、训练日志、决策日志、实验结果及可视化图表。

为保证实验过程的完整性与结果的可复现性，源代码、训练模型、算例数据、实验日志及结果文件均随本项目一并归档提交。

---

## 2. 源代码文件说明

| 序号 | 文件名 | 类别 | 功能说明 |
|---|---|---|---|
| 1 | `MAM_Deterministic_Equivalent_MILP.py` | 数学模型 | 构建 MAM-VPRP 问题的确定性等价混合整数线性规划（MILP）模型，用于获得确定性情形下的基准求解结果。 |
| 2 | `mam_simulation_environment.py` | 仿真环境 | 构建面向 MAM-VPRP 问题的仿真评估环境，用于在随机或动态情景下评价既定调度方案的运行表现。 |
| 3 | `evaluate_deterministic_solutions.py` | 基准求解与评估 | 调用确定性等价模型获得调度方案，并将所得方案置于仿真环境中进行性能评估，为后续算法比较提供基准结果。 |
| 4 | `EXP_ALNS.py` | 仿真优化算法 | 实现 SIM-ALNS 仿真优化算法，并与 EXP-ALNS 基准算法进行对比实验，用于评价不同启发式求解策略的效果。 |
| 5 | `MAM_DRL_ENV.py` | 强化学习环境 | 构建完整六动作空间下的动态调度强化学习环境，定义状态、动作、奖励及环境状态转移过程，为 PPO 智能体训练与测试提供交互环境。 |
| 6 | `TRAIN_drl.py` | 强化学习训练 | 基于动态调度环境训练 PPO 智能体，保存训练过程中得到的策略模型、阶段性模型及相关训练结果。 |
| 7 | `MAM_DRL_ENV_ablation.py` | 消融实验环境 | 构建动作空间消融实验下的动态调度环境，将动作空间调整为五动作设定，用于分析动作空间设计对算法性能的影响。 |
| 8 | `TRAIN_drl_ablation.py` | 消融实验训练 | 在五动作空间的消融环境下训练 PPO 智能体，并保存消融实验对应的策略模型及训练结果。 |
| 9 | `PPO_pic.py` | 结果可视化 | 对动态调度强化学习算法的求解结果及相关评价指标进行基础可视化分析。 |
| 10 | `PPO_pic_six_figures.py` | 结果可视化 | 对动态调度算法实验结果进行汇总绘图，用于生成论文中所展示的多幅性能比较图。 |
| 11 | `plot_ppo_ablation_boxplot.py` | 消融结果可视化 | 根据消融实验结果绘制箱线图，用于比较完整动作空间与消融后五动作空间条件下 PPO 算法性能的差异。 |

其中，`MAM_Deterministic_Equivalent_MILP.py`、`mam_simulation_environment.py` 和 `evaluate_deterministic_solutions.py` 用于完成确定性基准方案的生成与仿真评估；`EXP_ALNS.py` 用于实现仿真优化对比算法；`MAM_DRL_ENV.py` 与 `TRAIN_drl.py` 用于完成 PPO 动态调度智能体的环境构建与训练；`MAM_DRL_ENV_ablation.py` 与 `TRAIN_drl_ablation.py` 用于开展动作空间消融实验；其余文件用于生成实验结果图表并支持论文中的有效性分析。

## 4. 训练模型文件说明

动态调度强化学习部分在训练过程中生成了 PPO 智能体策略模型文件。该类文件用于保存训练得到的策略网络参数，是动态调度算法测试、性能评估以及消融实验复现的重要材料。模型文件均以 `.zip` 格式保存，不在论文正文或附录中展开显示，实际文件随本归档材料一并提交。

| 序号 | 文件或文件夹名称 | 功能说明 |
|---|---|---|
| 1 | `trained_models/full_6action/` | 存放完整六动作空间动态调度环境下训练得到的 PPO 模型文件。 |
| 2 | `trained_models/full_6action/models/` | 存放完整动作空间 PPO 训练过程中保存的阶段性模型、最优模型和最终模型。 |
| 3 | `checkpoint_stage_1.zip` 至 `checkpoint_stage_5.zip` | PPO 训练过程中按阶段保存的中间检查点模型，用于记录不同训练阶段的策略参数，便于模型回溯和阶段性评估。 |
| 4 | `mam_ppo_full_6action_best.zip` | 完整六动作空间下训练得到的最优 PPO 策略模型，用于论文中动态调度算法性能评估。 |
| 5 | `mam_ppo_full_6action_final.zip` | 完整六动作空间下训练结束后保存的最终 PPO 策略模型，用于保存训练完成时的最终策略参数。 |
| 6 | `ablate_action_0/` 至 `ablate_action_5/` | 存放不同动作消融设定下训练得到的 PPO 模型文件，用于分析各动作设计对动态调度算法性能的影响。 |
| 7 | `model_versions/` | 存放调参过程中生成的不同动作空间、不同奖励函数版本或不同随机种子条件下的 PPO 模型文件，用于模型版本记录和实验对比。 |

其中，`mam_ppo_full_6action_best.zip` 表示完整六动作空间下训练过程中获得的最优策略模型，`mam_ppo_full_6action_final.zip` 表示训练结束时保存的最终策略模型。`checkpoint_stage_1.zip` 至 `checkpoint_stage_5.zip` 为训练过程中的阶段性检查点文件，可用于观察模型在不同训练阶段的性能变化。消融实验模型存放于 `ablate_action_0/` 至 `ablate_action_5/` 文件夹中，分别对应去除或调整不同动作后的 PPO 训练结果，用于验证动作空间设计的有效性。

## 5. 训练日志、决策日志与实验结果说明

| 文件或文件夹名称 | 功能说明 |
|---|---|
| `ppo_runs/` | PPO 智能体训练过程中的运行结果保存目录，包括训练过程生成的模型、检查点或实验记录文件。 |
| `progress.csv` | PPO 训练过程记录文件，用于保存训练过程中的主要指标，支持训练收敛性分析和实验复现。 |
| `ppo_decision_logs.csv` | PPO 动态调度决策日志文件，用于记录智能体在仿真评估过程中的状态、动作、奖励及调度决策结果。 |
| `ppo_ablation_figures/` | PPO 动作空间消融实验结果图保存目录，用于存放消融实验生成的可视化图形。 |


程序运行时，首先读取 `instance/` 文件夹中的算例数据，然后调用确定性等价模型、仿真优化算法或 PPO 动态调度算法进行求解与评估。强化学习部分通过训练脚本生成 PPO 策略模型，并将训练过程中的日志文件保存至 `ppo_runs/` 文件夹中。模型训练完成后，可利用保存的模型文件对测试算例进行仿真评估，并将动态调度过程中的决策记录保存为 `ppo_decision_logs.csv`，将训练或评估过程中的指标记录保存为 `progress.csv`。

## 6. 运行环境说明

本项目基于 Python 语言实现。建议使用独立虚拟环境运行程序，以避免依赖库版本冲突。

建议环境如下：

```text
Python 3.8 或以上版本
```

常用依赖库包括：

```text
numpy
pandas
matplotlib
scipy
torch
gym 或 gymnasium
stable-baselines3
```

运行 MILP 数学模型部分，需要配置Gurobi他混合整数规划求解器。

## 7. 程序运行顺序

```text
1. 配置 Python 运行环境，并安装程序所需依赖库；
2. 检查 instance/ 文件夹中的算例数据是否完整；
3. 运行确定性等价模型及仿真优化算法，获得静态调度结果；
4. 运行 TRAIN_drl.py，训练完整六动作空间 PPO 智能体；
5. 运行 TRAIN_drl_ablation.py，训练动作空间消融实验下的 PPO 智能体；
6. 调用训练完成的模型文件，对测试算例进行仿真评估；
7. 读取 progress.csv、ppo_decision_logs.csv 及结果文件夹中的数据；
8. 运行 PPO_pic.py、PPO_pic_six_figures.py 或 plot_ppo_ablation_boxplot.py，生成论文中的实验结果图表。
```


## 8. 结果复现说明

为尽量复现论文中的实验结果，需要保证以下内容一致：

1. 算例数据一致；
2. 程序代码版本一致；
3. Python 依赖库及优化求解器配置一致；
4. PPO 训练参数一致；
5. 随机种子设置一致；
6. 加载的策略模型文件一致；
7. 仿真评估次数和评估场景一致。

由于强化学习训练过程具有一定随机性，即使代码和参数相同，重新训练得到的模型也可能与原模型存在差异。因此，论文中最终采用的训练完成模型文件应随项目一并归档。复现实验时，建议优先加载已保存的 `mam_ppo_full_6action_best.zip`、`mam_ppo_full_6action_final.zip` 以及对应消融实验模型，而不是完全重新训练模型。

1. 文件夹路径是否与代码中设置一致；

5. 优化求解器及其许可证是否配置完成；
6. 训练或评估所需随机种子、参数文件是否完整。
